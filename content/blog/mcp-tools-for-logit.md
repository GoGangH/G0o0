## 왜 MCP인가

Logit은 취업 준비생의 경험을 구조화하고 자기소개서 문항별로 추천하는 서비스입니다. 여기에 MCP를 더해 **사용자가 기존 AI에서 자신의 경험을 검색하고 자기소개서 작성까지 이어갈 수 있게** 했습니다.

MCP(Model Context Protocol)는 AI 클라이언트가 외부 도구를 호출하는 표준 방식입니다. Logit은 FastMCP로 도구 10개를 제공했습니다.

| 분류 | 도구가 하는 일 |
| --- | --- |
| 경험 | 검색, 저장 |
| 문항 | 문항별 경험 선택 |
| 지원 프로젝트 | 조회 |

위 표는 도구 10개 중 일부를 분류별로 묶은 것입니다.

## 도구 설계는 API 설계와 다르다

일반 API의 사용자는 문서를 읽은 개발자이지만, MCP 도구의 사용자는 모델입니다. 일반적으로 다음이 중요해집니다.

- **이름과 설명이 곧 사용법입니다.** 모델은 설명을 읽고 어떤 도구를 부를지 고릅니다.
- **응답은 작을수록 좋습니다.** 긴 응답은 컨텍스트를 그대로 차지합니다.
- **권한은 서버에서 확인합니다.** 모델이 보낸 인자를 그대로 믿으면 안 됩니다.

```python
# 구조를 설명하기 위한 예시 코드입니다.
@mcp.tool()
def search_experiences(query: str, limit: int = 5) -> list[dict]:
    """사용자의 경험 중 질문과 관련된 것을 찾습니다."""
    return experience_service.search(current_user(), query, limit)
```

## 추천 로직과 연결

도구 뒤에는 RAG 추천이 있습니다. 문항 60%, 직무 25%, 회사 15%로 점수를 결합하고, 경험 태그의 Jaccard 유사도와 역량 카테고리 보정을 적용했습니다. 도구는 입구일 뿐이고, 결과의 품질은 이 로직에서 나옵니다.

## 정리

MCP를 붙이는 일은 기능을 하나 더하는 것보다, 서비스의 입구를 하나 더 만드는 일에 가깝습니다.
